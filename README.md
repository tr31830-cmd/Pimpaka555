My E-Portfolio
เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สำหรับแนะนำตัวเอง แสดงทักษะ และรวบรวมผลงานที่เคยทำ พัฒนาด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งเครื่องมือหรือ Framework เพิ่มเติม
✨ คุณสมบัติ
- หน้าแรกสำหรับแนะนำตัว
- ส่วนประวัติและข้อมูลเกี่ยวกับฉัน (About Me)
- ส่วนแสดงทักษะและความสามารถ (My Skills)
- ส่วนแสดงผลงานพร้อมชื่อ คำอธิบาย และลิงก์ GitHub (My Projects)
- ส่วนข้อมูลติดต่อ (Contact Me)
- เมนูนำทางไปยังแต่ละส่วนของเว็บไซต์
- รองรับการแสดงผลบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ (Responsive Design)
- ใช้โทนสีม่วงเข้ม ม่วงอ่อน และชมพูในรูปแบบ Modern Design
🛠️ เทคโนโลยีที่ใช้
- HTML5 — กำหนดโครงสร้างเว็บไซต์
- CSS3 — ตกแต่งหน้าตาเว็บไซต์และรองรับหน้าจอหลายขนาด
- JavaScript — เพิ่มการเลื่อนหน้าเว็บไซต์อย่างนุ่มนวล
- Google Fonts (Prompt) — ใช้แสดงผลตัวอักษรภาษาไทย
📁 โครงสร้างไฟล์
my-e-portfolio/
└── index.html
เว็บไซต์นี้รวม HTML, CSS และ JavaScript ไว้ในไฟล์ index.html ไฟล์เดียว
🚀 วิธีเปิดใช้งาน
1. ดาวน์โหลดหรือคัดลอกไฟล์ index.html ไปไว้ในโฟลเดอร์ที่ต้องการ
2. ดับเบิลคลิกไฟล์ index.html
3. เว็บไซต์จะเปิดขึ้นในเว็บเบราว์เซอร์ เช่น Google Chrome, Microsoft Edge หรือ Firefox
ไม่จำเป็นต้องติดตั้งโปรแกรมเพิ่มเติมเพื่อเปิดดูเว็บไซต์
✏️ วิธีแก้ไขข้อมูล
เปิดไฟล์ index.html ด้วย Notepad หรือโปรแกรมแก้ไขโค้ด แล้วแก้ไขข้อมูลตัวอย่างต่อไปนี้ให้เป็นข้อมูลของเจ้าของเว็บไซต์
- ชื่อ-นามสกุล — ชื่อและนามสกุล
- โรงเรียนตัวอย่าง — ชื่อสถานศึกษา
- your@email.com — อีเมลที่ต้องการเผยแพร่
- https://github.com/ — ลิงก์โปรไฟล์ GitHub
- ชื่อและคำอธิบายโปรเจกต์ — เปลี่ยนเป็นผลงานจริง
- ลิงก์ GitHub ในแต่ละการ์ดผลงาน — เปลี่ยนเป็นลิงก์ Repository ที่เกี่ยวข้อง
🌐 การเผยแพร่ผ่าน GitHub Pages (ทางเลือก)
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ index.html ไปยัง Repository
3. เข้าเมนู Settings → Pages
4. ในส่วน Build and deployment เลือก Deploy from a branch
5. เลือก Branch main และโฟลเดอร์ / (root) แล้วกด Save
6. รอให้ GitHub Pages เผยแพร่เว็บไซต์ จากนั้นเปิด URL ที่ GitHub แสดงในหน้า Pages
📝 หมายเหตุ
- ข้อมูล ชื่อบุคคล อีเมล และลิงก์ในไฟล์เป็นข้อมูลตัวอย่าง ควรแก้ไขก่อนเผยแพร่
- ฟอนต์ Prompt โหลดจาก Google Fonts จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อแสดงฟอนต์ดังกล่าว หากไม่มีอินเทอร์เน็ต เว็บไซต์ยังเปิดได้ แต่จะใช้ฟอนต์สำรองของอุปกรณ์
- ควรตรวจสอบว่าไม่มีข้อมูลส่วนตัวที่ไม่ต้องการเผยแพร่ก่อนนำเว็บไซต์ขึ้นออนไลน์
